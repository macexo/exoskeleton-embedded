# Member submissions

Follow [NOVEMBER_WORKSHOP.md](../../../NOVEMBER_WORKSHOP.md). Each person copies [`_template/`](_template/) into their own uniquely named folder (for example, `majock/`; use your own name). Complete only identity checking and register writing in your `imu_spi.c`; keep short notes/results in your README. Configuration and sample reading are deferred.

Each PR contains only that member's folder. Build and hardware checks happen at the workshop after the leads set up the CubeIDE board project; copy any fixes back into your submission before committing.
